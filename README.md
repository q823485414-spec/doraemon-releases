# 哆啦A梦 · 本地免费模型网关（下载页）

> 把你在各个 AI 软件（Codex、Qoder、Trae、WorkBuddy…）里**已经登录的账号额度**，
> 攒到一起，变成一个「本地网关」。然后**别的软件也能来蹭这些额度**——省钱、不用翻墙、一个地方统一管。

**👉 [点这里下载最新版](../../releases/latest)**（下载 `Doraemon-Setup-*.exe`）

> 本仓库**只放安装包**（下载页）；**源码不公开**。

---

## 一、装它要几步？

**就一步：双击下载的安装包，一路下一步。**

装完桌面会多个图标。完事。

> 不用装 Python，不用配环境，不用管端口。包里全带了。

## 二、装完怎么用？

1. 双击桌面的 **哆啦A梦** 图标 → 它缩到**右下角托盘**（时钟旁边的小图标）。
2. **双击那个托盘图标** → 面板就打开了（一个网页界面）。
3. 面板里能看到：有哪些模型、用掉多少、哪个软件在用。

**就这些。** 平常它自己安安静静待在后台干活，你不用管。

## 三、要不要填什么东西？

### ✅ 不用！默认装完就能用。

原理是「**复用你已经登录的软件**」：
- 你电脑上**装了并登录了**哪个 AI 软件（Qoder、Trae、WorkBuddy…），它就能用那个的额度。
- 没装的，那部分用不了，**但不影响其它**。

### 只有想用「直连官方云」的那几家才要填

火山、智谱、阶跃、硅基流动… 这些要填 API key：
打开安装目录里的 `gateway\keys.json`，把你要用的那家 key 粘进去，保存重启。

> 不会填、不想填？**那就别填**。想用某一家了再回来填那一家。

## 四、把别的软件接进来

面板的**「客户端」页**点一下「一键接入」，自动帮你把 Codex / Claude Code 等配置改好。

手动填也简单，就一个网址：

```
http://127.0.0.1:57331/v1
```

（API Key 随便填，填 `gateway-local`。）

## 五、出问题咋办？

| 现象 | 怎么办 |
|---|---|
| 找不到它在哪 | 看**右下角托盘**，有个小图标 |
| 面板打不开 | 浏览器直接开 `http://127.0.0.1:8799` |
| 某模型用不了 | 那家多半没登录 / 没填 key，换一个模型 |
| 想关掉它 | 托盘图标**右键 → 退出** |
